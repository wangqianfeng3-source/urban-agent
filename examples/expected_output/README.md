# 预期产出样例

这个目录固化了**一次真实闭环运行的全部产物**（`python -m urban_agent.demo` 在玩具数据上的输出），
让每位营员在写代码之前就知道"做完应该长什么样"。

## 文件清单

| 文件 | 是什么 | 对应结营交付物 |
|---|---|---|
| `history.json` | 每轮迭代的结构化日志：得分、违规、动作、证据 | 实验数据（论文图表的直接来源） |
| `plan_v1.geojson` … `plan_v4.geojson` | 每一版方案快照（v1 初版 → v4 达标版） | 方案演化数据集 |
| `report.md` | 给规划师看的迭代报告（含确认签字栏，交互工作台可直接导出） | 演示与校准实验材料 |
| `portfolio_report.md` | 五策略 Top 5 方案比选报告（`python -m urban_agent.compare` 的真实输出） | 结营比选报告的样例 |
| `final_report_template.md` | 结营个人小结模板（1-2 页） | 每人一份 |

## 一次成功运行的判定标准（玩具数据）

- 4 项初始硬违规在 2 轮内全部消除；
- 综合得分从 0（一票否决）爬升至 ≥75 达标；
- 每一轮的每个修改动作都有理由、都可追溯到某条违规或建议；
- `report.md` 让不看代码的规划背景老师能复述整个过程。

五天结营时，理想状态是同样的四类产物在**预置复兴岛数据 + LLM 编辑器**上产生，
外加：小型校准数据（`runs/calibration/`）、LLM vs 规则式对照小表、
以及一场观众能亲手操作的交互演示（"改方案 → 看评分 → AI 建议 → 人拍板"）。
