## 一、全员部分（约 3-4 小时）

### 1. 环境搭建（30 分钟）

```bash
# 1) 安装 miniconda（已有 Anaconda 可跳过）
# 2) 创建环境
conda create -n urban python=3.12 -y && conda activate urban
# 3) 克隆仓库并安装依赖
git clone https://github.com/wangdongjie100/urban-renewal-agent.git && cd urban-renewal-agent
pip install -r requirements.txt
# 4) 验证：四条命令都应成功
python -m pytest tests/ -q               # 应显示 22 passed
python -m urban_agent.demo               # 应显示 "✅ 达标通过"
python -m urban_agent.compare            # 应输出五策略比选排名表
streamlit run app/streamlit_app.py       # 打开交互工作台，动手点一轮
```

跑不通先查 FAQ（README 底部），再到群里贴**完整报错**求助。

### 2. 读三份文档（1.5 小时）

按顺序读，读完试着回答括号里的问题：

1. `docs/任务书.md`（五天各做什么？从输入分析到 Top 5 比选的整条流程是怎么走的？五条设计建议是什么、为什么？）
2. `docs/plan_schema.md`（一个"方案"在机器里长什么样？为什么营期内尽量不动它？）
3. `docs/evaluator_interface.md`（硬约束和软评分的区别？为什么反馈要机器可执行？）

### 3. 在交互工作台里玩一轮（40 分钟，最重要的一项）

打开 `streamlit run app/streamlit_app.py`，亲手做：

- 在"方案与人工编辑"里试着把历史保护地块 P10 改成商业用地——看看会发生什么，想想为什么；
- 在"AI 建议 · 人拍板"里点"让 AI 提建议"，否掉一条、采纳一条；
- 在"Top 5 方案比选"里输入"打造零碳示范街区，同时提升街区活力"，点生成——看五张策略卡各自跑出什么方案、为什么"保守渐进"够不到达标线（提示：它拒绝改用地性质）；选一个方案载入，回到编辑页继续改；
- 点"自动运行"，在"迭代历史"里看得分怎么爬到 75 以上；
- 思考：如果把达标线拉到 90，会发生什么？（动手试）

### 4. 项目背景（30 分钟）

- 立项 PPT《城市数实空间智能体》（群文件）——重点第 3-5、25-29 页；
- 上海城市更新政策与"三师联创"机制（PPT 第 9-11 页已梳理，泛读即可）。

## 二、分轨部分（按你可能加入的组，约 2-4 小时）

### AI 轨（A 组及各维度组的技术同学）

**建议阅读：**
1. LLM function calling 官方教程（通义 dashscope 或 DeepSeek 文档，任选其一并动手跑通示例）；
2. ReAct: *Synergizing Reasoning and Acting in Language Models*（ICLR 2023）——"智能体循环"的原理；
3. *Judging LLM-as-a-Judge with MT-Bench*（NeurIPS 2023）——用 LLM 打分的偏差与校准，直接对应我们评估模块的风险。

**小练习：** 写一个 ≤100 行脚本：定义两个工具（如查天气 + 算术），让 LLM 通过 function calling 串联调用回答一个两步问题。

### GIS 轨（B 组及要算空间指标的同学）

**建议阅读：** GeoPandas 官方 10 分钟教程（动手做完）；Shapely 的 buffer/distance/within；OSMnx 抓路网算最短路的示例。

**小练习：** 用 GeoPandas 读 `data/sample/fuxing_demo.geojson`，输出各用地类型面积占比表 + 一张按用地着色的地图。

### 规划轨（各维度组的规划背景同学）

**建议阅读：** 面向本期两个维度——**人和社会**：《上海市街道设计导则》四大导向与五类要素（PPT 第 22-23 页有摘要），关注功能混合、Citywalk 友好；**能源与碳**：城市/片区尺度碳排放核算的分部门方法（建筑/交通/废弃物/碳汇，刘超老师组杨浦研究，群文件），关注地块级排放怎么算。复兴岛专项规划要点（PPT 第 6-8 页）；熵权 TOPSIS 复习。

**小练习（最有价值的一项，二选一或都做）：**
1. 为你想加入的维度写 **2 条硬约束 + 2 条软指标草案**，每条含：指标名、定义、计算公式、数据需求、阈值出处。格式见 `docs/evaluator_interface.md` 末尾模板；
2. 读 `urban_agent/strategies.py` 内置的 5 张策略卡，然后**写 1 张新策略卡草稿**（如 TOD 导向、历史风貌友好、职住平衡），包含：适用情形、维度取舍、给 AI 的思维提示、动作倾向。你的卡会被比选系统实际调用，结营报告里有署名。
